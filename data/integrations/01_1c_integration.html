Интеграция FinPay с 1С

Официальный модуль

FinPay поставляет официальный модуль для 1С:Управление торговлей и 1С:Комплексная автоматизация версий 2.4 и выше. Модуль устанавливается как внешняя обработка (файл .epf) через конфигуратор без изменения основной конфигурации базы.

Синхронизация статусов оплаты

Модуль опрашивает статус платежей через API каждые 5 минут по умолчанию (настраивается от 1 до 60 минут) и обновляет статус заказа в 1С. Рекомендуется дополнительно настроить приём вебхуков напрямую на сервер 1С (при наличии внешнего IP) для мгновенного обновления статуса без ожидания следующего опроса.

Сопоставление номеров заказов

При создании платежа в 1С в поле metadata.order_id передаётся номер заказа 1С — это позволяет однозначно сопоставить платёж FinPay с документом в учётной системе при получении вебхука или ответа API, независимо от внутреннего payment_id FinPay.

Выгрузка отчётов о комиссиях

Модуль умеет выгружать ежемесячный реестр операций с удержанной комиссией в формате, совместимом с регламентированной отчётностью 1С — для сверки с закрывающими документами, формируемыми FinPay автоматически 5 числа каждого месяца.

Известные ограничения

Модуль не поддерживает работу с подписками (рекуррентными платежами) — для этого сценария рекомендуется прямая интеграция через API или SDK (см. data/api/04_sdk.html).
