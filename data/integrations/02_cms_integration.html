Интеграция FinPay с CMS (Bitrix, Tilda)

Bitrix

Официальный модуль оплаты FinPay доступен в маркетплейсе решений Bitrix24 и «1С-Битрикс: Управление сайтом». Устанавливается как платёжная система в разделе «Магазин» → «Оплата» → «Способы оплаты». Поддерживает все методы оплаты FinPay: карты, СБП, рассрочку.

Tilda

Встроенная интеграция через блок «Оплата» в конструкторе Tilda — достаточно указать публичный API-ключ FinPay в настройках магазина Tilda, без установки дополнительных модулей. Поддерживаются только карты и СБП, рассрочка через Tilda-интеграцию недоступна.

WooCommerce и другие CMS

Для CMS без официального модуля (WooCommerce, OpenCart, кастомные решения) рекомендуется прямая интеграция через REST API или готовый JavaScript-виджет FinPay Checkout, встраиваемый через <script>-тег на странице оформления заказа.

Тестирование интеграции CMS

Перед переключением магазина в боевой режим необходимо провести не менее 3 тестовых оплат в sandbox (см. data/api/05_sandbox.html) с проверкой корректного обновления статуса заказа в CMS после получения вебхука.

Частая ошибка настройки

Наиболее частая ошибка при интеграции с CMS — использование тестового API-ключа в боевом магазине (или наоборот) после переключения окружения: приводит к тому, что оплаты формально проходят в sandbox, а заказы в CMS создаются как оплаченные без реального списания денег с клиента.
