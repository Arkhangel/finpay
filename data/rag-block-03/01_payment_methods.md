# Способы оплаты в FinPay

FinPay поддерживает несколько каналов приёма платежей для бизнеса, подключённого
через lk.finpay.ru.

## Банковские карты
- Поддерживаемые платёжные системы: Visa, Mastercard, МИР.
- Для всех карточных платежей обязателен проход через 3-D Secure — платёж без
  подтверждения через 3-D Secure автоматически отклоняется на стороне банка-эмитента.
- Данные карты (номер, CVV) не проходят через серверы продавца — используется
  токенизация на стороне FinPay (см. также раздел про PCI DSS в отдельном документе
  по безопасности).

## Система быстрых платежей (СБП)
- Оплата по QR-коду на кассе или по платёжной ссылке для дистанционных продаж.
- Подтверждение занимает несколько секунд через приложение банка клиента.
- Комиссия по СБП регулируется отдельно от карточной (см. документ про тарифы).

## Электронные кошельки
- ЮMoney и QIWI поддерживаются, но не включены по умолчанию — подключаются
  отдельно через персонального менеджера аккаунта.
- Для подключения нужно оставить заявку в личном кабинете, раздел «Способы оплаты».

## Выбор способа оплаты на кассе
Если у продавца подключено больше одного способа, на странице оплаты клиент видит
все доступные варианты и выбирает сам. Продавец может отключить любой способ
оплаты для конкретной кассы через настройки виджета оплаты.
