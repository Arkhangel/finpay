Тестовый режим (sandbox) FinPay

Доступ к sandbox

Sandbox доступен сразу после регистрации аккаунта, до прохождения верификации юрлица. Используется отдельный набор тестовых API-ключей с префиксом test_ — они не работают в продакшен-окружении и наоборот.

Тестовые карты

  • 4242 4242 4242 4242 — успешная оплата любой суммой.
  • 4000 0000 0000 0002 — эмулирует отказ банка (payment.failed, код card_declined).
  • 4000 0000 0000 9995 — эмулирует недостаточно средств (код ошибки insufficient_funds).

Срок действия и CVC тестовых карт — любые валидные по формату значения, реальная проверка не выполняется.

Эмуляция вебхуков

В личном кабинете, раздел «Sandbox» → «Вебхуки», можно вручную инициировать отправку тестового вебхука любого типа события на настроенный endpoint — удобно для тестирования обработчика без необходимости проводить реальную тестовую оплату.

Ограничения sandbox

Максимум 1000 тестовых операций в сутки на аккаунт. Данные в sandbox хранятся 90 дней и затем автоматически удаляются. Sandbox нельзя использовать для нагрузочного тестирования — при обнаружении аномального трафика (более 50 req/sec) IP временно блокируется на уровне инфраструктуры.

Переход в продакшен

После активации аккаунта тестовые ключи продолжают работать отдельно от боевых — переключение интеграции на боевой режим требует явной замены ключей в конфигурации, автоматического переключения не происходит.
