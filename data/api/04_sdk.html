SDK для интеграции с FinPay

Официальные SDK

FinPay поддерживает официальные SDK для двух языков: Python (pip install finpay-sdk) и Node.js (npm install @finpay/sdk). Оба SDK покрывают полный набор операций v2 API: платежи, возвраты, выплаты, вебхуки, работу с подписками.

Инициализация клиента (Python)

Клиент создаётся с обязательным параметром api_key и опциональным timeout (по умолчанию 30 секунд). SDK автоматически подставляет заголовок Idempotency-Key для методов создания платежа, если он не передан явно — на основе UUID v4, сгенерированного один раз при вызове метода.

Обработка ошибок

SDK выбрасывает типизированные исключения: FinPayAuthError (401), FinPayValidationError (422), FinPayRateLimitError (429, содержит атрибут retry_after), FinPayServerError (5xx). Это избавляет интеграцию от разбора кодов ответа вручную.

Встроенный retry

Обе SDK по умолчанию делают до 3 повторных попыток при ошибках 429 и 5xx с экспоненциальной задержкой (1с, 2с, 4с). Поведение можно отключить параметром retry=False при создании клиента, если интеграция реализует собственную логику повторов.

Неофициальные SDK

  • PHP — сторонний пакет finpay-php на Packagist, поддерживается сообществом, не покрывает выплаты (payouts).
  • Go — сторонний пакет, покрывает только приём платежей, без вебхуков и подписок.

FinPay не гарантирует SLA поддержки для неофициальных SDK.
